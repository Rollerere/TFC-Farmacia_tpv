# 02. Introducción y alcance

## Cómo elaborar este apartado

Describe el problema o necesidad, los objetivos, los usuarios destinatarios, el alcance y las limitaciones. Evita incluir funcionalidades que todavía no estén acordadas.

## Ejemplo ficticio

Una web estática presenta información de una pequeña asociación y permite consultar sus actividades. El alcance incluye navegación entre páginas, diseño adaptable y un formulario con validación en el navegador. El envío real de mensajes queda fuera del alcance hasta que se defina un servicio que lo procese.
