# 13. Glosario y referencias

## Glosario

| Término | Definición |
|---|---|
| Requisito funcional | Comportamiento o servicio que debe proporcionar el sistema. |
| Requisito no funcional | Cualidad o restricción verificable del sistema. |
| Caso de uso | Descripción de cómo un actor interactúa con el sistema para alcanzar un objetivo. |
| Caso de prueba | Conjunto de condiciones, datos, pasos y resultados esperados para verificar un comportamiento. |
| Regresión | Comprobación de que un cambio no ha introducido fallos en comportamientos anteriores. |
| Trazabilidad | Relación entre requisitos, diseño, pruebas y resultados. |
